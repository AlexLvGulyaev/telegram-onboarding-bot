# 💼 Telegram Onboarding Bot · BUSINESS_VALUE

**Проект:** telegram-onboarding-bot  
**Дата:** 2026-08-11  
**Статус:** Предварительная бизнес-оценка кейса.

---

## 1. Проблема

Компании тратят время сотрудников-наставников на повторяющееся объяснение базовых правил новым членам команды. При этом качество онбординга нестабильно: зависит от загрузки наставника, его настроения и опыта.

## 2. Решение

Telegram-бот, который:
- самостоятельно проводит сотрудника по материалу;
- проводит тестирование и оценивает ответы;
- сохраняет результаты в PostgreSQL для отчётности;
- легко адаптируется под разные темы через внешние конфиги.

## 3. Целевые пользователи

- HR-отделы и отделы обучения;
- руководители команд, вводящие новых сотрудников;
- компании с удалённой/гибридной работой, где асинхронный онбординг критичен.

## 4. Преимущества

- **Масштабируемость:** один бот может обучать неограниченное число сотрудников одновременно.
- **Консистентность:** каждый сотрудник получает одинаковый материал и критерии оценки.
- **Экономия времени:** наставник подключается только при сложных вопросах, а не на рутинном объяснении.
- **Прозрачность:** результаты тестирования фиксируются в БД и доступны для аналитики.
- **Универсальность:** замена темы не требует разработки — только JSON-конфиг.

## 5. Варианты применения

- Корпоративный онбординг (правила команды, регламенты).
- Обучение продавцов (правила работы с клиентами, скрипты).
- Курсы по информационной безопасности и комплаенсу.
- Техническая адаптация (архитектура, процессы разработки).

## 6. Риски

- Качество диалога зависит от выбранной LLM и качества промпта.
- Необходимость API-ключей и расходов на токены.
- Сессии хранятся в памяти — при перезапуске бота прогресс теряется.
- Требуется ручное E2E-тестирование для каждой новой темы.

## 7. Следующие шаги для коммерциализации

- Добавить веб-админку для управления темами и просмотра результатов.
- Реализовать персистентное хранение FSM-состояния.
- Добавить аналитику: статистика по темам, сотрудникам, вопросам.
- Подготовить white-label версию с брендированием под клиента.
