## 🔧 4. Infrastructure Validation

### 4.1. Docker Compose

- [ ] `docker compose up -d` без ошибок
- [ ] Все контейнеры healthy
- [ ] Контейнеры не перезапускаются (stable)
- [ ] Volume `postgres_data` создан корректно

### 4.2. База данных

- [ ] PostgreSQL запущен
- [ ] Таблицы созданы (`training_results`, `training_topics`, `bot_settings`)
- [ ] Подключение по проброшенному порту работает

### 4.3. Сеть

## 🔌 5. Integration Validation

### 5.1. Telegram

- [ ] Telegram Bot Token валиден (бот отвечает на `/start`)
- [ ] Long-polling запущен (лог: `Start polling for bot …`)

### 5.2. OpenAI

- [ ] `OPENAI_API_KEY` валиден (бот генерирует обучающий блок)
- [ ] JSON-ответ соответствует `response-schema.json`
- [ ] Токены учитываются (`total_tokens_spent` > 0 в БД)

### 5.3. Полный пользовательский сценарий

- [ ] Тестовое сообщение отправлено боту
- [ ] Бот ответил корректно
- [ ] Результат записан в БД
- [ ] Обработка ошибок работает (невалидный ввод: 1 символ, фото/стикер)
