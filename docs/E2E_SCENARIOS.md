# 🎬 Telegram Onboarding Bot · E2E_SCENARIOS

**Проект:** telegram-onboarding-bot  
**Дата:** 2026-08-11  
**Статус:** Чек-лист ручных E2E-сценариев.

---

## 1. Сценарий «Happy path»

| Шаг | Действие пользователя | Ожидаемый результат |
|-----|----------------------|---------------------|
| 1 | Отправить `/start` | Бот приветствует, называет тему, просит имя |
| 2 | Отправить имя | Бот начинает обучение по материалу |
| 3 | Задать вопрос по материалу | Бот отвечает строго по материалу |
| 4 | Сказать «Готов к тесту» | Бот переходит к testing и задаёт вопрос 1 |
| 5 | Ответить на вопрос | Бот оценивает ответ, даёт feedback, задаёт вопрос 2 |
| 6 | Повторить шаг 5 до вопроса N | Бот последовательно задаёт все вопросы |
| 7 | Ответить на последний вопрос | Бот переходит в completed, показывает итог и процент |
| 8 | Проверить PostgreSQL | В `training_results` появилась запись с правильными полями |

## 2. Сценарий «Отмена сессии»

| Шаг | Действие пользователя | Ожидаемый результат |
|-----|----------------------|---------------------|
| 1 | Отправить `/start` и имя | Сессия активна |
| 2 | Отправить `/cancel` | Бот подтверждает отмену |
| 3 | Отправить сообщение без `/start` | Бот просит отправить `/start` |

## 3. Сценарий «Смена темы»

| Шаг | Действие пользователя | Ожидаемый результат |
|-----|----------------------|---------------------|
| 1 | Отправить `/topic` | Бот показывает список доступных тем |
| 2 | Отправить `/topic customer-service` | Бот подтверждает смену темы |
| 3 | Отправить `/start` | Бот начинает обучение по новой теме |
| 4 | Пройти тест | Результат сохраняется с новой темой |

## 4. Сценарий «Некорректный ввод»

| Шаг | Действие пользователя | Ожидаемый результат |
|-----|----------------------|---------------------|
| 1 | Отправить `/start` | Бот просит имя |
| 2 | Отправить один символ | Бот просит указать имя хотя бы из двух символов |
| 3 | Отправить фото/стикер | Бот просит отправить текст |

## 5. Сценарий «Управление темами администратором»

| Шаг | Действие пользователя | Ожидаемый результат |
|-----|----------------------|---------------------|
| 1 | Отправить `/admin` от имени администратора | Бот показывает меню администратора |
| 2 | Отправить `/new_topic` | Бот запрашивает id темы |
| 3 | Ввести id, название, описание, материал | Бот сохраняет тему в PostgreSQL |
| 4 | Отправить `/list_topics` | Бот показывает список тем с отметкой активной |
| 5 | Отправить `/set_topic <id>` | Бот подтверждает смену темы по умолчанию |
| 6 | Отправить ту же команду от не-администратора | Бот отказывает в доступе |
| 7 | Пересобрать и перезапустить контейнер | Активная тема восстановлена из `bot_settings`; тема не пропадает |
| 8 | Проверить БД | Записи `training_topics` и `bot_settings` актуальны |
