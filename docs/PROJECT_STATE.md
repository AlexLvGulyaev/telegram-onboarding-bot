## 🎯 1. Project Summary

Telegram-бот для поэтапного обучения сотрудников новому материалу и автоматического тестирования. Бот ведёт диалог в роли AI-наставника, объясняет тему, отвечает на вопросы, переходит к тесту из заданного числа вопросов, оценивает ответы и сохраняет результат в PostgreSQL.

**Ключевые параметры:**

| Параметр | Значение |
|----------|----------|
| Канал | Telegram |
| Язык | Python 3.11, aiogram 3.x |
| LLM | OpenAI API с JSON Schema ответа |
| Хранилище результатов | PostgreSQL 16 |
| Контейнеризация | Docker Compose |
