## 🎯 1. Project Summary

Telegram-бот для поэтапного обучения сотрудников новому материалу и автоматического тестирования. Бот ведёт диалог в роли AI-наставника, объясняет тему, отвечает на вопросы, сам решает, когда переходить к тесту, задаёт вопросы по одному, оценивает ответы и сохраняет результат в PostgreSQL. Темы обучения конфигурируются без правки кода — через JSON-файлы или админ-команды бота.

**Ключевые параметры:**

| Параметр | Значение |
|----------|----------|
| Канал | Telegram |
| Язык | Python 3.11, aiogram 3.x |
| LLM | OpenAI API (Chat Completions + Embeddings) с JSON Schema ответа |
| Хранилище результатов и тем | PostgreSQL 16 (asyncpg) |
| Сессии | Redis (`RedisStorage`), `REDIS_URL`; пустое значение — `MemoryStorage` (dev) |
| Контейнеризация | Docker Compose (bot + db + redis) |

## ✅ 6. Decision

**Принято:** продолжить как публичный портфолио-проект.

**Утверждённые решения:**

- MVP реализован на Python 3.11 + aiogram 3.x + OpenAI API.
- Универсальные темы: единственный runtime-источник — `training_topics` в БД; `topics/<id>.json` — импортные шаблоны, загружаемые `/import_topic` (перестали быть вторым SOT и автосидированием); активная тема — в `bot_settings`, а не в `.env`.
- Промпты вынесены из хардкода в `prompts/v1/` и разделены на два слоя: пользовательский (`system.md`) и технический (в коде).
- Guard-логика фаз в сервисном слое: LLM отвечает за язык, код — за жизненный цикл.
- Дедупликация вопросов двух уровней: лексическая + embedding (0.72).
- Сессии в Redis (`RedisStorage`; пустой `REDIS_URL` — MemoryStorage для dev).
- Публичный репозиторий развёрнут в `AlexLvGulyaev/telegram-onboarding-bot`.
